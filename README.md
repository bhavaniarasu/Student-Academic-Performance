# Student Academic Performance Management System

## Project Description
This project is designed to manage and analyze student academic performance.

The system allows users to:
- Store student academic details
- Calculate GPA
- Calculate grades
- Display student details
- Identify the topper among students

## Concepts Used
- Inheritance
- Virtual Functions
- Virtual Base Class
- Function Overloading
- Operator Overloading
- Friend Function

## Features
- Grade calculation using virtual functions
- Undergraduate and postgraduate student categories
- GPA calculation using different evaluation schemes
- Input and output operator overloading using `>>` and `<<`
- Topper identification using a friend function
- Virtual base class to avoid ambiguity in multiple inheritance

## Student Categories
- Undergraduate Student
- Postgraduate Student

## How to Run
1. Open the source file in a suitable compiler.
2. Compile the program.
3. Run the program.
4. Enter the required student details.
5. View the GPA, grade, student details, and topper information.
